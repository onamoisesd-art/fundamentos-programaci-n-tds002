# Notas de Repaso - Ciclos

- **while**: se usa cuando no sabemos cuántas veces se repetirá, depende de una condición.  
  Ejemplo: validar PIN hasta 3 intentos.

- **for**: se usa cuando sabemos el número exacto de repeticiones.  
  Ejemplo: imprimir tabla de multiplicar del 1 al 12.

- **do-while**: se usa cuando queremos que el ciclo se ejecute al menos una vez.  
  Ejemplo: menú que se repite hasta que el usuario elija salir.
